# Requirements Docs

Сюда складываются требования к системе и отдельным подсистемам.

Подходящий состав документа:

- цель;
- функциональные требования;
- нефункциональные ограничения;
- acceptance criteria;
- открытые вопросы.

Если требования относятся к уже утвержденному решению, рядом должна быть ссылка на соответствующий ADR или архитектурный документ.
