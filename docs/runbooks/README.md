# Runbooks

Сюда складываются практические инструкции:

- локальная настройка окружения;
- запуск сервисов;
- отладка типовых проблем;
- эксплуатационные процедуры.

Runbook должен описывать шаги так, чтобы их мог повторить другой участник проекта без дополнительного контекста.

## Текущие документы
- `wmi-liveness-hang.md` — окна «отваливаются»/сообщения уходят не в то окно из-за залипшего WMI; причина, фикс (плагин ушёл с `Get-CimInstance` на `Get-Process`) и восстановление.
- `orphans-and-topic-rebind.md` — осиротевшие процессы плагина глотают входящие; перепривязка топика к окну.
- `duplicate-window-message-split.md` — в топик доходит лишь часть сообщений / окна падают по OOM; два живых окна на одну папку + исчерпание commit; фикс дедупа в боте (`bridge/registry.py`) и операционное восстановление.
